These captures show the app with fictional accounts and transactions only. The demo database used to prepare the captures is separate from the app's normal local database. Amounts intentionally have no currency symbol, matching Pennywise's currency-neutral design.

Pennywise supports account registration, sign-in, and sign-out. Transactions are stored per account; the dashboard summarizes the current month and shows up to eight recent entries. This MVP does not include separate reports, charts, or a full transaction-history page.
